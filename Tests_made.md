# Tests Made And Results

The following table shows the tests i have made or could make so far. "<->" means that transfer works in both directions in the combination of pocket computers. "-" means nothing works with that combination. "->" means working from PC 1 to PC 2 and finally "<-" means that it works from PC 2 to PC 1.


| PC 1 | direction | PC 2 |
| :--- | :---: | ---: |
|------|-------|------|
| PC-1401 | <-> | PC-1403 |
| PC-1401 | <-> | PC-1401 |
| PC-1251 | - | PC-1401 |
| PC-1251 | - | PC-1403 |
| PC-1251 | -> | PC-1260 |
| PC-1260 | -> | PC-1403 |
| PC-1401 | <-> | PC-1460 |
| PC-1460 | -> | PC-1360 |
|------|-------|------|

The EA-129C was built and released by Sharp to enable program and data transfer between pocket computers of the same type. At least that was what i found in commercials. So my guess is that it would always work, to transfer data from PC-1251 to PC-1251 and so on. Unfortunately i do not have multiple PC-1251s, PC-1460s to test it. So it's up to you.
